# ChatGPT Codex 鐵人賽 2026

本專案記錄 2026 年鐵人賽的每日文章、實作程式碼與學習筆記。

## 專案結構

```text
.
├── README.md
├── AGENTS.md
├── LICENSE
└── Day01/ ~ Day31/
    └── README.md
```

每個 `DayXX/` 目錄對應一天的文章內容。文章、範例程式、圖片與其他素材，請放在對應的每日目錄中。

## 閱讀方式

從 [Day01](Day01/README.md) 開始，依序閱讀至 [Day31](Day31/README.md)。每日文章發布後，再將文章連結與摘要補回對應目錄及本 README。

## 開發與追蹤

```bash
git clone <repository-url>
cd chatgpt-codex-ironman-2026
git status
```

提交前請確認沒有 API 金鑰、密碼或其他個人敏感資料。
