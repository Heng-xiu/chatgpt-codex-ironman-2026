# 下載資料夾
同層資料夾`示範用資料夾-發票整理`就是當日所需用到的發票內容

# 文章中提供的提示詞
```
請處理「發票整理」資料夾中的所有台灣發票與收據圖片。

逐一查看每份憑證，並擷取以下資訊：

- 憑證類型
- 店家／賣方名稱
- 賣方統一編號
- 發票或憑證日期
- 發票號碼
- 買受人統一編號（如果有）
- 品名或交易內容摘要
- 未稅金額（如果可辨識）
- 營業稅額（如果有）
- 總計金額
- 課稅別（應稅／零稅率／免稅／無法判斷）
- 建議費用分類
- Confidence Score
- 是否需要人工確認（Needs Review）

如果任何資訊無法可靠辨識，請不要猜測，將該欄位留空並標記為 Needs Review。

將結果整理成一份只有 1 個工作表的 Excel，每張憑證一列，並額外加入：

- 原始檔名
- 處理後檔案路徑
- Review Notes

將 Excel 儲存在專案根目錄。

接著建立「已處理發票」資料夾，依發票日期將處理完成的憑證複製到對應的 YYYYMM 子資料夾，例如：

已處理發票/202609

日期無法確認的憑證請放入：

已處理發票/Needs\_Review

請保留來源資料夾中的原始檔案，不要刪除、覆寫或修改原始圖片。

完成後，告訴我：

1. 共處理多少份憑證
2. 多少份需要人工確認
3. Excel 儲存位置
4. 最常出現哪些辨識問題
```
